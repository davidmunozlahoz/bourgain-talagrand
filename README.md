# In a Banach lattice, the RNP and the KMP are equivalent

Source code of an expository paper on the theorem of Bourgain and Talagrand (1981): in a
Banach lattice, the Radon–Nikodým property and the Krein–Milman property are equivalent ([Dans Un Espace de Banach Reticule Solide, La Propriété de Radon-Nikodým et Celle de Krein-Milman Sont Équivalentes](https://www.jstor.org/stable/2043994)).

The site is static: `index.html` with its styles in `src/css/`, scripts in `src/js/` and
images in `assets/`. Open `index.html` in a browser to read it locally.
